## 질문 1

달력 인식 모델은 92일 중 12일에서만 개선됐는데도
전체 WAPE를 약 50% 낮췄다.
이것이 가능한 이유를 WAPE의 계산 방식과 날짜별 오차 규모를 이용해 설명하라.

- WAPE는 전체 절대오차의 합을 전체 실제 수요의 합으로 나눈 값
    분자: 전체 절대오차의 합
    분모: 전체 실제 수요의 합

기존 모델의 전체 절대오차가 공휴일과 연휴 다음 주에 집중됨

달력 인식 모델이 바로 그 대형 오차 날짜를 선택적으로 수정함

따라서 92일 중 12일만 개선돼도 전체 절대오차 합계가 크게 감소함
-> WAPE가 약 50% 감소

정상 날짜 79일은 두 모델의 예측이 동일하므로 성능을 훼손하지 않았다.

## 질문 2

일반 주말에서 달력 인식 모델은 WAPE와 sMAPE가 좋아졌지만
RMSE는 조금 나빠졌다.
세 지표가 서로 다른 결론을 낼 수 있는 이유를 설명하라.

### WAPE
전체 절대오차를 전체 실제 수요로 나눈다.
- 이용량이 큰 역.날짜의 절대오차 영향이 큼
- 오차를 제곱하지 않음

### sMAPE
각 관측치의 상대오차를 계산한 뒤 평균한다.
- 각 역.날짜가 하나의 관측치로 평균에 참여
- 수요 규모가 작은 역도 상대적으로 의미 있는 영향

### RMSE
오차를 제곱한 뒤 평균하고 제곱근을 취한다.
- 큰 오차를 제곱 -> 소수의 극단적인 오차에 매우 민감

따라서 이번 주말 결과는 다음처럼 해석할 수 있다.
- 전체 절대오차의 합과 관측치별 평균 상대오차는 감소했다.
- 하지만 일부 역.날짜의 큰 오차가 조금 증가 -> 제곱오차에 민감한 RMSE는 악화

달력 인식 모델이 대부분의 주말 관측치에서는 소폭 좋아졌지만, 소수의 큰 오차가 증가해 RMSE만 나빠졌을 가능성이 있다.


## 질문 3

현재 실험이 rolling one-day-ahead 예측이라는 것은 무슨 의미인가?
9월 30일에 10~12월 전체를 한꺼번에 예측하는 방식과
데이터 사용 가능 범위가 어떻게 다른지 설명하라.

- 가장 최근 시점까지의 데이터가 있어서 이걸 가지고 예측날 하루를 예측하는 방법
- 즉 9월 30일에 10~12월 전체를 한꺼번에 예측하는 방식과 다르게 10월 1일은 9월 30일까지의 데이터로, 12월 10일의 경우는 12월 9일까지의 데이터가 존재해야 하며, 이 데이터를 가지고 12월 10일을 예측하는 차이
- 9월 30일에 10~12월을 한꺼번에 예측하는 고정 시점 방식에서는 10월과 11월에 새로 관측한 실제 수요를 11월.12월 예측에 사용할 수 없다.

Rolling one-day-ahead
매일 실제값이 새로 들어옴 -> 다음 날 예측에 최신 관측값 사용 가능

Fixed-origin multi-step
9월 30일 한 시점에서 92일 예측 -> 10월 이후 실제값 사용 불가
