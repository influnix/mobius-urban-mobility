# Data

이 저장소에는 원본 대중교통 데이터가 포함되지 않습니다.

## 사용 데이터

- 데이터명: 서울교통공사 역별 일별 시간대별 승하차인원 정보
- 대상 기간: 2025-01-01 ~ 2025-12-31
- 분석 범위: 서울교통공사 1~8호선
- 원본 파일명: `subway_2025.csv`

## 저장 위치

다운로드한 원본 CSV를 다음 경로에 저장합니다.

```text
data/raw/subway_2025.csv
```

## 주의사항

이 프로젝트는 집계 승하차 데이터를 사용합니다.

개별 이용자의 이동 경로나 행동을 추적하거나 식별할 수 없으며,
역 단위 패턴을 개인 단위 행동으로 해석하지 않습니다.
